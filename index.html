Ajustes de SantIA

🔐 Conexión protegida

Las claves API están guardadas en Vercel y no aparecen dentro de esta página.

🔊 Leer respuestas automáticamente

SantIA generará su voz natural después de cada respuesta. Esto consume la API de voz.

🎙️ Dictado

El micrófono utiliza el reconocimiento de voz disponible en Chrome y está configurado en español de Chile.

📎 Documentos

SantIA puede leer PDF con texto, Word DOCX, TXT, Markdown, CSV, JSON y HTML. Los PDF escaneados como imagen necesitarán OCR en una versión posterior.
